# 전역 지침 (kjham-cc 가 배포 — 레포별 CLAUDE.md·AGENTS.md 가 우선)

## 언어

- 사용자에게 보이는 글은 모두 한국어로 쓴다. 코드·명령어·경로·식별자·오류 원문은 그대로 둔다.
- 서브에이전트에게 일을 맡길 때도 "보고는 한국어로"를 지시에 넣는다.

## 결과 카드

파일을 수정했거나 명령을 실행한 턴의 **마지막 답변** 끝에 아래 카드를 붙인다. 단순 질의응답, 중간 진행 메시지에는 붙이지 않는다.
여러 세션을 오가는 사람이 이 카드만 보고 상황을 파악한다.
요청한 작업이 끝나 이어질 일이 다른 작업이면 `남은 일`에 "`/clear` 후 새 세션으로"를 붙인다. 이어 할 맥락은 작업 기록 파일에 남긴다.
각 줄은 한 문장으로 짧게 쓰고, 해당 없는 줄은 `없음`으로 둔다.

```markdown
---
**결과** ✅ 완료 | ⚠ 부분 완료 | ❌ 실패   (셋 중 하나만)
- 한 일: 무엇을 했는지
- 변경: 바뀐 파일·설정 (커밋 여부)
- 확인: 무엇으로 검증했고 무엇은 못 했는지
- 남은 일: 다음에 할 것
- 결정 필요: 사용자가 정해야 할 것
```
