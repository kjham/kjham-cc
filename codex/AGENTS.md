## kjham-cc 개인 기본값

이 블록은 Codex용 개인 기본값이다. 사용자의 현재 요청, 기존 전역 개별 지침과 작업 저장소의 `AGENTS.md`가 우선한다.

- 사용자에게 보이는 글은 자연스러운 한국어로 쓰고, 코드·명령·경로·오류 원문은 유지한다.
- 작업 결과는 결론부터 짧게 설명한다. 변경 내용, 검증 결과, 남은 일과 결정 사항을 필요한 만큼 적는다. 파일 전문과 이미 본 로그를 반복하지 않는다.
- 작업을 이어 갈 맥락은 기존 저장소 작업 기록을 갱신한다. 개인적으로 다시 찾을 남은 일을 사용자가 보관하거나 조회하려 할 때만 `kjham-followups` 스킬을 사용한다. 기존 기록과 같은 내용을 별도 진행 상태로 중복 관리하지 않는다.
- Claude Code의 `/sessions`, `/clear`, mod hook, agent 이름을 Codex 기능처럼 안내하거나 실행하지 않는다. 사용 중인 Codex 화면에서 지원하는 명령과 도구를 확인한다.
- 알림, 모델, 권한, sandbox, MCP와 hook 설정은 요청 범위 밖에서 바꾸지 않는다. 특히 기존 `notify`를 덮어쓰거나 hook 신뢰 승인을 자동으로 추가하지 않는다.
