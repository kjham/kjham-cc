# 한국어 글·장표에서 AI 티 걷어 내기

목표는 읽는 사람이 내용에만 집중하게 하는 것이다. 탐지기를 속이는 것이 목표가 아니다. 문장을 일부러 어색하게 만들거나 오타를 넣지 않는다.

## 바꾸지 않는 것

- 수치, 날짜, 식별자, 경로, 명령, 고유명사, 인용문.
- 조건과 범위를 정하는 말: "P1 이상", "최대 3시간", "신규·재발만". 매끄럽게 고치다가 "중요한", "일정 시간", "일부"로 바뀌면 사실이 사라진다.
- 글쓴이가 일부러 쓴 표현. 말투 표본이 있으면 그 말투가 기준이다.

## 절차

1. 대상을 끝까지 읽는다. 말투 표본이 있으면 먼저 읽는다.
2. 아래 점검표로 걸리는 곳을 찾는다. 고치기 전에 수치·식별자·조건 목록을 따로 적어 둔다.
3. 고친다. 고칠 말이 없는 문장은 지운다 — 빈 문장을 다른 빈 문장으로 바꾸지 않는다.
4. 2에서 적어 둔 목록이 고친 글에 그대로 있는지 대조한다.
5. 한 번 더 읽어 새로 생긴 티를 찾는다. 한 패턴을 누르면 옆 패턴이 나온다(대비 구문을 지우면 콜론 뒤 반전이 생기는 식).
6. 무엇을 고쳤는지 유형별 건수로 짧게 알린다. 고친 곳을 전부 나열하지 않는다.

## 글 점검표

| 티 나는 것 | 예 | 고치는 방향 |
|------------|-----|-------------|
| 대비 구문 | "단순한 도구가 아니라 동료입니다" | 하려는 말만 쓴다 |
| 셋으로 묶기 | "빠르고, 안전하고, 확장 가능한" | 실제 개수대로. 하나면 하나 |
| 예고 문구 | "핵심은", "중요한 점은", "결론적으로", "정리하면" | 지우고 내용부터 |
| 빈 수식어 | "혁신적", "강력한", "원활한", "효율적으로", "다양한" | 숫자나 사실로 바꾸거나 지운다 |
| 흐리기 | "~할 수 있습니다", "~것으로 보입니다", "~라고 할 수 있습니다" | 확인한 것은 단정, 모르는 것은 모른다고 |
| 번역투 | "~에 의해", "~를 가지다", "~에 대한", "~를 통해", "~함에 있어" | 우리말 어순으로. "배포에 의해 반영된다" → "배포하면 반영된다" |
| 명사 나열 제목 | "코드 리뷰 개요" | 주장 한 줄: "같은 지적을 매일 새 업무로 만들지 않는다" |
| 끝맺음 요약 | 문단·장 끝의 "이처럼 ~는 중요합니다" | 지운다 |
| 자문자답 | "왜 그럴까요? 바로 ~" | 답만 쓴다 |
| 과한 연결어 | "또한", "뿐만 아니라", "나아가", "한편" 이 문장마다 | 대부분 지워도 뜻이 통한다 |
| 같은 리듬 | 모든 문장 길이가 비슷, 모든 항목이 같은 구조 | 내용이 많은 곳은 길게, 적은 곳은 짧게 |
| 강조 남발 | 굵은 글씨·이모지·느낌표가 줄마다 | 문단이나 장에 강조 한 곳 |
| 줄표와 콜론 반전 | "결과는 — 놀랍게도 —", "답은 하나: ~" | 쉼표나 마침표로 풀어 쓴다 |
| 과잉 존대·맞장구 | "좋은 질문입니다", "도움이 되셨길 바랍니다" | 지운다 |
| 영어 병기 | "가시성(visibility)" 을 매번 | 처음 한 번만, 또는 우리말만 |

## 화면 점검표 (장표·웹 화면)

렌더링한 이미지를 놓고 본다.

| 티 나는 것 | 고치는 방향 |
|------------|-------------|
| 보라·파랑 그라디언트 배경, 유리 효과 | 템플릿 색, 단색 바탕 |
| 모든 장이 "아이콘 + 카드 3장" | 내용의 모양을 따른다. 흐름은 흐름도, 비교는 표, 수치는 큰 숫자 하나 |
| 뜻 없는 장식 아이콘·이모지 | 정보가 없는 그림은 뺀다 |
| 장마다 꽉 찬 글머리표 | 말로 할 것은 발표자 노트로 |
| 가상의 예시 화면·숫자 | 실제 캡처와 실제 수치. 없으면 비워 두고 알린다 |
| 둥근 모서리·그림자·테두리가 겹겹이 | 하나만 쓴다 |
| 모든 제목 가운데 정렬 | 좌측 정렬 |
| 장마다 다른 색 강조 | 강조색 하나 |

## 고친 뒤 알릴 것

- 유형별 건수(예: 대비 구문 4, 번역투 7, 빈 수식어 5).
- 사실 대조 결과: 수치·식별자·조건이 모두 남아 있는지.
- 고치지 못한 것: 채울 사실이 없어 비워 둔 문장, 글쓴이가 직접 정해야 하는 표현.
