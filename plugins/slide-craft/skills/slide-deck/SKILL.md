# 발표 자료 만들기

장표를 바로 만들지 않는다. 아래 순서로 간다. 유료 서비스(Gamma, Canva 등)에 내용을 올리지 않는다.

## 1. 입력 확인

아래를 대화와 파일에서 찾는다. 없는 것만 한 번에 묻는다. 사용자가 "끝까지 진행"이라고 했으면 기본값으로 간다.

| 항목 | 기본값 |
|------|--------|
| 청중과 그들이 이미 아는 것 | 같은 조직의 개발자 |
| 발표 시간 | 20분 → 본문 10~12장 |
| 산출물 형식 | 편집 가능한 PPTX. 화면 공유만 하면 단일 HTML |
| 사내 템플릿(`.pptx`·`.potx`) | 없으면 흰 바탕 단색 |
| 재료 문서 | 대화에서 가리킨 파일 |
| 발표자의 말투 표본 | 있으면 읽고 따른다 |

## 2. 재료

- 재료 문서에서 **실제 수치·식별자·화면**을 뽑는다. 가상의 예시 숫자와 가상 화면을 만들지 않는다.
- 재료에 없는 사실이 필요하면 지어내지 말고 "확인 필요" 목록에 올린다.
- 뽑은 사실마다 출처 파일을 적어 둔다. 6단계 대조에 쓴다.

## 3. 스토리라인

장표를 만들기 전에 `storyline.md` 를 쓴다. 장마다 세 줄이다.

```
## 3. 같은 지적을 매일 새 업무로 만들지 않는다      ← 제목은 주장 한 줄
- 근거: 지문 = 저장소 + 파일 + 관점 + 코드 한 줄 / 상태 신규·잔존·재발
- 모양: 표 (판별 기준 4개)                           ← 흐름도·표·큰 숫자·캡처·코드 중 하나
```

- 제목만 이어 읽어도 발표 내용이 전달돼야 한다. "개요", "소개", "현황" 같은 명사 제목은 주장으로 바꾼다.
- 장의 모양은 내용을 따른다. 흐름은 흐름도, 비교는 표, 수치 하나는 큰 숫자, 실물은 캡처.
- 한 장에 주장 하나. 넘치면 장을 나눈다.
- 스토리라인을 사용자에게 보이고 넘어간다. "끝까지 진행" 지시가 있으면 보이기만 하고 계속한다.

## 4. 다이어그램

- 발표 전체를 꿰는 그림 한 장을 먼저 만들고, 절마다 해당 구간만 강조해 다시 쓴다.
- PPTX 면 네이티브 도형으로 그린다(발표 직전까지 고칠 수 있다). 복잡하면 `.drawio` 나 Mermaid 로 만들어 SVG·PNG 로 넣고 원본 파일을 같이 둔다.
- 상자 안 글은 6단어 이하. 화살표에는 무엇이 넘어가는지 적는다.

## 5. 제작과 렌더링 검수

**PPTX.** `pptx` 스킬이 있으면 그 스킬의 절차를 따른다. 템플릿이 있으면 레이아웃을 먼저 고르고 구조(추가·삭제·순서)를 내용보다 먼저 맞춘다. 없으면 `anthropics/skills` 의 `document-skills` 설치를 안내하고 PptxGenJS 스크립트로 만든다.

**HTML.** 빌드 도구 없는 단일 파일. 웹폰트를 넣는다. `frontend-design` 스킬이 있으면 따른다.

**규칙.**

- 제목 36~44pt, 본문 14~16pt 이상, 여백 0.5인치 이상, 본문 좌측 정렬.
- 한글 폰트는 발표 PC 에 있는 것으로 지정한다(맑은 고딕, Pretendard 등). 없는 폰트를 지정하지 않는다.
- 차트는 네이티브 차트로 넣는다.
- 장당 강조 한 곳. 말로 할 내용은 발표자 노트로 옮긴다.

**검수.** 만든 뒤 반드시 이미지로 렌더링해 장마다 본다. PPTX 는 LibreOffice 로 PDF 로 바꾼 뒤 `pdftoppm -jpeg -r 150`, HTML 은 브라우저 스크린샷. 글자 넘침·겹침·잘림·빈 칸·남은 placeholder·깨진 한글을 찾아 고치고, 고친 장만 다시 렌더링한다. 렌더링 도구가 없으면 검수를 못 했다고 보고에 적는다 — 했다고 쓰지 않는다.

## 6. 정제와 사실 대조

1. `humanize-ko` 스킬로 글과 화면을 정제한다.
2. 정제 뒤 장표의 모든 수치·식별자·조건을 2단계에서 적어 둔 출처와 대조한다. 바뀌었거나 빠진 것을 되돌린다.

## 7. 보고

- 산출물 경로, 장 수.
- 렌더링 검수를 했는지, 몇 번 돌렸는지.
- "확인 필요" 목록: 재료에 없어 비워 둔 사실, 발표 전에 다시 조회할 수치.
- 발표자가 소리 내어 읽어 보고 자기 말이 아닌 문장을 고치라는 안내. 이 단계는 대신할 수 없다.
